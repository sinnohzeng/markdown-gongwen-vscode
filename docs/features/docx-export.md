# 一键导出公文 DOCX

> 本文档是 DOCX 导出功能的唯一规范来源。代码中的样式参数均以此为准。

## 做什么

点一下按钮，把当前 Markdown 文件变成一份符合 GB/T 9704-2012《党政机关公文格式》的 Word 文档。

不需要装 Pandoc，不需要跑大模型，一切都是确定性的机械转换。

## 怎么做

```
Markdown → remark 解析 → mdast 语法树 → ast-to-docx 映射 → docx 库打包 → .docx 文件
```

用 `docx` npm 包直接生成 OOXML。样式表整体自定义，只含本文列出的样式；库自带的 List Paragraph、Strong 等默认样式不进入导出文件。

代码分四层，各管各的事：

```
src/export/
├── constants.ts        页面尺寸、字号、行距、字体，全是命名常量
├── gbt9704-styles.ts   样式定义、页面布局、页脚
├── ast-to-docx.ts      语法树到 Word 文档的纯函数映射（不碰 VS Code API）
├── image-resolver.ts   图片路径解析、尺寸读取、版心缩放
└── export-command.ts   按钮点击后的交互流程编排
```

`ast-to-docx.ts` 是纯函数，拿到语法树就能出文档，跟 VS Code 没有半点关系，Jest 直接测。

## 版面规格

依据 GB/T 9704-2012。偏差允许 ± 1mm。

| 项目 | 数值 |
|------|------|
| 纸张 | A4 纵向（210 × 297mm） |
| 上边距 | 37mm |
| 下边距 | 35mm |
| 左边距 | 28mm |
| 右边距 | 26mm |
| 版心 | 156 × 225mm |
| 每页 | 22 行，每行 28 字 |
| 行距 | 固定值 28 磅（560 twip） |
| 正文首行缩进 | 2 个字符（640 twip） |
| 正文对齐 | 两端对齐 |

## 字体

公文里来来回回就这几种字体。每种中文字体配一个固定的英文搭档，代码里用拼音命名，一看就知道是什么。

| 变量名 | 中文 | 英文 | 用在哪 |
|--------|------|------|--------|
| `XiaoBiaoSong` | 方正小标宋简体 | Times New Roman | 公文大标题 |
| `HeiTi` | 黑体 | Arial | 一级标题、表头 |
| `KaiTi` | 楷体 | Arial | 二级标题、强调 |
| `FangSong` | 仿宋 | Times New Roman | 正文、三四级标题 |
| `SongTi` | 宋体 | Times New Roman | 页码 |
| `CodeFont` | 宋体 | Consolas | 代码块 |

配对逻辑：黑体和楷体走无衬线路线，配 Arial；仿宋和宋体走衬线路线，配 Times New Roman。

方正小标宋为 GB/T 9704 标准指定字体，需用户自行获取安装。未安装时 Word 会自动回退到宋体。macOS 上 Word 会把 SimHei 回退到 Heiti SC、把 FangSong 回退到 STFangsong，不用在代码里操心平台差异。

所有字体一律不用 `_GB2312` 后缀。

## 标题

GB/T 9704 的标题层级靠字体区分，不靠字号大小。除了大标题用二号字，其余全是三号。

| 级别 | Markdown | Word 样式 | 字体 | 字号 | 加粗 | 对齐 |
|------|----------|-----------|------|------|------|------|
| 公文标题 | `#` | 标题 | 方正小标宋 | 二号 22pt | 否 | 居中，不缩进 |
| 一级 | `##` | 标题 1 | 黑体 | 三号 16pt | 否 | 左对齐，缩进 2 字符 |
| 二级 | `###` | 标题 2 | 楷体 | 三号 16pt | 否 | 同上 |
| 三级 | `####` | 标题 3 | 仿宋 | 三号 16pt | **是** | 同上 |
| 四级 | `#####` | 标题 4 | 仿宋 | 三号 16pt | 否 | 同上 |
| 更深 | `######` | 标题 4（回退） | 仿宋 | 三号 16pt | 否 | 同上 |
| 无 | 无 | 标题 5 / 6 / 7 | 仿宋 | 三号 16pt | 否 | 同上 |

公文标题层级止于四级。Markdown 的 `######`（H6）没有对应的公文级别，回退到标题 4 样式。样式表仍定义标题 5 到 7，与标题 4 同外观，用户在 Word 里手动套用时不会冒出 Word 默认的蓝色 Calibri。

缩进 2 字符、回行顶格（GB/T 9704 第 7.3.3 条）。公文标题居中，不缩进。

所有标题（含公文标题）均启用“与下段同页”（`keepNext: true`），防止标题出现在页底而正文翻到下一页。标题 1 到 7 的样式带大纲级别 0 到 6，Word 导航窗格与目录域按级别识别；公文标题不设大纲级别。

标题内的 `**强调**`、行内代码、图片占位同样不打直接格式，按标题样式原样输出。

各级标题的编号（“一、”“（一）”“1.”“（1）”）写在 Markdown 文本里，不靠 Word 自动编号。

样式 ID 与 `w:name` 一律用 Word 内建名称（`heading 1`、`TOC Heading`、`toc 1`、`footnote text`）。Word 靠 `w:name` 识别内建样式并显示中文名，自造名称会在样式面板里冒出重复项。

标题段落的文字不打直接格式，字体、字号、加粗全部由样式承担：在 Word 里改“标题 1”样式即可全局生效，目录域也不会把黑体、楷体带进目录条目。

## 强调

Markdown 里的 `**加粗**` 导出后不是粗体，而是换成楷体。公文讲究用字体区分强调，不用粗细区分。

| 项目 | 值 |
|------|-----|
| 中文 | 楷体 |
| 英文 | Arial |
| 字号 | 三号 |
| 加粗 | 否 |

## 页码

GB/T 9704 第 7.5 条，逐字对照。

| 项目 | 规格 |
|------|------|
| 字体 | 宋体四号（14pt） |
| 数字 | 半角阿拉伯数字 |
| 一字线 | `—`（U+2014 Em Dash，占一个汉字宽度） |
| 格式 | `—1—` |
| 位置 | 版心下边缘之下，一字线上距版心 7mm |
| 奇数页 | 居右空一字 |
| 偶数页 | 居左空一字 |

页码里全是英文字符和 Em Dash，Word 实际渲染出来的是 Times New Roman。

## 引用块

Markdown 引用（`>` 段落）按正文版式排版，仅用字体区分。中文公文排版不使用斜体，也不加背景底纹。

| 项目 | 值 |
|------|-----|
| 字体 | 楷体（KaiTi + Arial）三号 |
| 斜体 | 否 |
| 底纹 | 无 |
| 缩进 | 首行缩进 2 字符，回行顶格（与正文一致） |
| 对齐 | 两端对齐 |

引用内的嵌套内容（列表等）同样继承楷体。

## 列表

列表条目按公文正文段落排版：首行缩进 2 字符、回行顶格。不使用 Word 的“文本之前”左缩进，序号（`1. ` / `• `）作为文字内容输出。

| 项目 | 值 |
|------|-----|
| 缩进 | 首行缩进 2 字符（640 twip），无左缩进 |
| 对齐 | 两端对齐 |
| 有序序号 | 按 `start` 起始值连续编号 |
| 嵌套 | 每层加深首行缩进 320 twip |

## 表格

全框线风格，所有单元格四边均有边框。

| 项目 | 值 |
|------|-----|
| 宽度 | 撑满版心（100%） |
| 边框 | 0.5pt 实线，四边统一 |
| 表头 | 黑体四号，不加粗，水平居中（忽略列对齐标记） |
| 表体 | 仿宋四号，按 GFM 列对齐标记（`:--` 左、`:-:` 中、`--:` 右）对齐，默认左对齐 |
| 单元格 | 垂直居中，左右边距 0.19cm，首行缩进归零 |

黑体本身笔画已重，再加粗反而难看，所以表头不加粗。

## 图表题注

依据 GB/T 7713 族标准（GB/T 9704 不涉及题注）：表题在表上、图题在图下，均与图表同页不拆分。

### 语法约定（Markdown 写法）

| 题注 | Markdown 写法 |
|------|--------------|
| 图题 | 独占段落的单张图片，alt 即图题：`![图1 总体架构](路径)` |
| 表题 | 紧邻表格上方的独占段落：`表1 五年成本对照` |

alt 不匹配 `^图\s*\d+` 的图片（装饰图等）不产题注；行内混排的图片不产题注。表题段后面不跟表格时，按普通正文输出。

### 渲染参数

| 项目 | 值 |
|------|-----|
| 表题位置 | 表上方，`keepNext` 与表同页 |
| 图题位置 | 图下方，`keepWithPrevious` 与图同页 |
| 对齐 | 居中 |
| 字体 | 黑体（数字/字母 Times New Roman） |
| 字号 | 小四 12pt |
| 编号间隔 | 编号与题注文字之间渲染为 1 个汉字空（全角空格），如“表1　五年成本对照” |
| 末尾标点 | 无（不自动添加） |
| 间距 | 题注段上下各约半行（14pt = 280 twip） |
| 图片段行距 | 图片独占段单倍行距；文字与图片混排的段落、含图片的表格单元格用“最小值 28 磅”。固定行距会把比行高的图片裁成一条，Word 与 WPS 都如此 |

## 目录

在 WPS 或 Word 里插入自动目录是主路径，插件不强制生成目录。导出文件预先定义好目录相关样式，插入后不用再手动改字体：

| 样式 | 规格 |
|------|------|
| 目录标题（`TOCTitle`） | 黑体三号，居中，无缩进，固定 28 磅，与下段同页 |
| `TOC Heading`（Word 内建，中文 Word 显示为“TOC 标题”） | 全部继承目录标题，自身不带格式，平时隐藏 |
| 目录 1 / 2 / 3（`toc 1` 到 `toc 3`） | 仿宋三号，固定 28 磅，左对齐，逐级左缩进 2 字，页码右对齐到版心右缘（156mm）并带点线前导 |

Word 的自动目录给“目录”二字套内建的 `TOC Heading`，插入后直接就位。WPS 的自动目录插出来的“目录”二字不带任何样式（2026-09-17 实测），选中它，在样式面板点“目录标题”即可。WPS 的内建样式表止于 Word 97 那一代，不认识 `TOC Heading`，会把它当用户样式原样显示英文名，所以面板上可见的只留“目录标题”一条，`TOC Heading` 隐藏起来只给 Word 用。

Markdown 里也可以写一个独占段落的 `[TOC]`（`[[TOC]]` 亦可，大小写不限）。只认纯文本：行内代码、强调或链接里的 `[TOC]` 按普通文字输出，讲解这个写法的文档不会冒出目录。导出时它变成“目录”标题段加目录域 `TOC \o "1-2" \h`，收录一级、二级标题（Markdown `##`、`###`）。Word 打开时提示更新域，确认后生成条目；WPS 若未自动生成，在目录上右键选“更新域”。

只有文档含目录域时才写入 `updateFields`，普通文档打开 Word 不弹“是否更新域”提示。

## 样式表

导出文件的 styles.xml 只含下列样式。GB/T 9704 未涉及的项目按党政机关长文档惯例取值，依据列标明层级。

| 样式（Word 显示名） | styleId | 规格 | 依据 |
|------|------|------|------|
| 正文（文档默认） | Normal / docDefaults | 仿宋三号，固定 28 磅，首行缩进 2 字，两端对齐 | GB/T 9704 7.3.4 |
| 标题 | Title | 方正小标宋二号，居中，无缩进 | GB/T 9704 7.3.1 |
| 标题 1 到 4 | Heading1 到 Heading4 | 见“标题”一节 | GB/T 9704 7.3.3 |
| 标题 5 到 7 | Heading5 到 Heading7 | 同标题 4 | 国标止于四级，沿用四级外观 |
| 目录标题、TOC 标题、目录 1 到 3 | TOCTitle、TOCHeading、TOC1 到 TOC3 | 见“目录”一节 | 机关长文档惯例 |
| 超链接 | Hyperlink | 黑色，无下划线 | 公文全文纯黑 |
| 脚注文本、尾注文本 | FootnoteText、EndnoteText | 仿宋小五 9pt，单倍行距，无首行缩进 | 类比 GB/T 7713.2-2022 附录 B |
| 脚注引用、尾注引用 | FootnoteReference、EndnoteReference | 上标 | Word 惯例 |
| 默认段落字体 | DefaultParagraphFont | 无格式（字符样式基类） | OOXML 要求 |
| 普通表格 | TableNormal | 单元格左右边距 108 twip | Word 默认值 |

插件不提供脚注、尾注的 Markdown 语法，样式定义好供用户在 Word 里加注时直接使用。

## 交互

编辑器右上角有个 Word 文档图标（dark/light 两套 SVG），只在 Markdown 文件里出现。

两种导出方式：

| 命令 | 入口 | 行为 |
|------|------|------|
| 导出公文 DOCX | 按钮与命令面板 | 弹出保存对话框 |
| 快速导出公文 DOCX | 命令面板 | 直接存到 .md 同目录 |

流程：检查未保存修改，弹保存对话框，显示可取消的进度条，进度收尾后弹完成通知（含文件大小），通知上可选“打开文件”或“在文件管理器中显示”。

完成/失败通知必须在 `withProgress` 的回调 Promise resolve 之后再弹：带按钮的通知要等用户交互才 resolve，若在进度回调内 `await`，进度通知会一直挂住不消失（v2.0.x 曾有此 Bug）。

导出路径自动记住，下次默认用上次的目录。出错时弹窗带“查看日志”按钮，点开就是输出面板“DOCX 导出”通道里的完整记录，每条带时间戳与级别。

## 验收标准

- 导出的 DOCX 符合 GB/T 9704-2012 版面规格（纸张、边距、行距、字号）
- 标题层级字体映射正确（方正小标宋 / 黑体 / 楷体 / 仿宋）
- 引用块为楷体正文版式（无斜体、无底纹、首行缩进）
- 列表段落首行缩进 2 字符、回行顶格（无“文本之前”左缩进）
- 表格为全框线风格（0.5pt 实线），撑满版心；表头黑体不加粗居中，单元格垂直居中
- 样式表只含本文列出的样式，标题文字不带直接格式
- `[TOC]` 段输出“目录”标题段与目录域，且仅此时写入 `updateFields`
- 图题在图下方、表题在表上方，均居中、黑体小四、与图表同页
- 题注编号与文字之间为 1 个汉字空，末尾无标点
- alt 不匹配“图N”的图片不产题注，表题段不重复输出为正文
- 页码格式为 `—N—`，奇偶页位置正确
- 图片等比缩放不超出版心宽度
- 空文档、frontmatter、Mermaid 等边缘情况不崩溃

## 边缘情况

| 场景 | 处理 |
|------|------|
| 空文档 | 生成只有一个空段落的有效 DOCX |
| YAML Frontmatter | 跳过，不输出 |
| Mermaid 图表 | 等宽代码块加提示文字 |
| LaTeX 公式 | 等宽纯文本 |
| 远程图片 | 黑色占位文字 |
| 本地图片找不到 | 黑色占位文字加汇总警告 |
| 图片太宽 | 等比缩放到版心 156mm |
| 图片 alt 非“图N”格式 | 不产题注，按普通图片输出 |
| 表题段后无表格 | 按普通正文段落输出 |
| 超链接 | 输出为黑色普通文字 |
| `[TOC]` 段带其他文字或格式 | 不识别为目录标记，按普通正文输出 |
| 代码块、公式源码 | 左对齐，无首行缩进，灰色底纹 |
| 引用块内的表格 | 照常输出为表格 |
| 文字颜色 | 统一黑色，绝无蓝色 |
