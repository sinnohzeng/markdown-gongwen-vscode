## 明确不做（理由闭环）

| 项 | 理由 |
|----|------|
| TS8 升级 | typescript major 升级风险大，本轮不做 |
| Jest→Vitest | 821 用例 3 秒，无痛点，迁移无收益 |
| package.nls 全套 i18n | 成本远超收益，markdownDescription 中文化已覆盖用户需求 |
| 导出快捷键 | 用户未要求，避免键位冲突 |
| walkthroughs 向导 | 过度工程化 |
| 远程图片下载 | 超出本轮范围，另立 spec |
| release-please | 现有 release.js 流程已验证可用 |
| noUncheckedIndexedAccess 全仓 | 改动面过大，与本轮目标不符 |
| 覆盖率指标 | 只补便宜高价值用例，不追数字 |
| parser.ts 装饰引擎重构 | 重构另立 spec，本轮不扩大范围 |
| export 管线拆 npm 包 / mdast 处理器注册表 / webview 消息 zod 校验 | 过度工程化，当前规模不需要 |
| mermaid 位图导出、LaTeX OMML 导出 | 另立 spec；但本轮实现导出降级丢弃时的用户可见提示「以下内容未在 DOCX 中呈现：…」，拒绝静默丢失 |
| 上游同步 | 评估后不做——上游自 v1.24.2（2026-06-12）零新增合并提交，本仓 07b1934 已择优移植覆盖，维持每月 ls-remote 巡检策略（ADR upstream-sync.md）；盯防候选：CJK 表格 PR #137/#116/#136 一旦上游合并再评估移植 |
